# Portfólio Profissional — Daiane Rosana

> **Apoio Administrativo** | Gestão de Processos, Eficiência & Suporte Institucional

Portfólio moderno, sofisticado e feminino com paleta Bordô / Vinho Escuro e Ouro Rosé, desenvolvido com HTML5, CSS3 avançado e JavaScript puro. Acompanha um **Painel de Controle Administrativo Completo** para edição sem código.

---

## ✨ Principais Características

- **Paleta Premium**: Bordô / Vinho profundo (`#150810`), acentos em ouro rosé (`#c4869a`) e detalhes translúcidos.
- **Efeitos Dinâmicos**: Pétalas de rosas caindo no hero, halo rotativo no avatar, luzes difusas e cards com glassmorphism.
- **Painel Administrativo (`admin.html`)**: Permite alterar em tempo real todas as cores do site, fontes, textos, seções, contatos e fazer upload de novas imagens.
- **Totalmente Responsivo**: Otimizado para desktop, tablets e smartphones (iPhone / iPad).
- **Sem Dependências**: Desenvolvido em Vanilla JS e CSS puro, carregamento ultrarrápido e sem necessidade de build.

---

## 📂 Estrutura do Projeto

```
├── index.html        # Página principal pública do portfólio
├── style.css         # Estilos, variáveis de tema e animações
├── data.js           # Fonte de dados central e persistência local
├── app.js            # Lógica de renderização dinâmica e interações
├── admin.html        # Painel administrativo
├── admin.css         # Estilos do painel de controle
├── admin.js          # Lógica de edição, upload e customização de cores
├── server.js         # Servidor local Node.js (opcional)
└── assets/
    ├── avatar.jpg    # Foto profissional
    └── logo.jpg      # Monograma DR em ouro rosé
```

---

## 🚀 Como Executar

### Opção 1: Direto no Navegador
Abra o arquivo `index.html` diretamente em qualquer navegador moderno.

### Opção 2: Servidor Local Node.js
```bash
node server.js
```
Acesse em: [http://localhost:3000](http://localhost:3000)

---

## 🔐 Acesso ao Painel Admin

Para manter o visual limpo para visitantes, o link administrativo não fica exposto na navegação pública:

- **URL Direta**: Acesse `admin.html` no navegador (ex.: `http://localhost:3000/admin.html`).
- **Atalho de Teclado**: Na página principal, pressione `Ctrl + Shift + A` para ir direto ao painel.
